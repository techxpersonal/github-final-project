# Contributing
All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for considering a contribution to Simple Interest Calculator.

## How to contribute

1. Fork the repository and create a focused branch.
2. Make your change, keeping the calculator simple and accessible.
3. Test the script with valid and invalid numeric input.
4. Open a pull request that explains the change and its motivation.

## Bug reports

Use a GitHub issue for bug reports. Include the command you ran, the input supplied, the expected behavior, and the actual behavior.

## Documentation and enhancements

Documentation improvements and enhancement ideas are welcome. For larger changes, open an issue first so the approach can be discussed before implementation.

By contributing, you agree that your contribution may be released under this repository's Apache 2.0 license.
